# Hooky Website

Marketing showcase and documentation site for [Hooky](https://github.com/pranav256/Hooky) — the 100% free and open-source AI video clipper.

## Tech Stack
- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
