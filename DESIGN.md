# Hooky website

## Product

Hooky is an open-source video clipper with a local Studio and optional Gemini moment selection. The website should feel like a focused editing desk: useful, warm and direct. Interviews, transcript lines, selected cuts and finished portrait clips provide the context; Ember orange marks the chosen moment against charcoal surfaces.

## Existing system

Use the shared Ember palette in `public/brand.css`, based on Eidova's Dark Orange tokens. Preserve system sans/mono fonts, the 8px radius, native buttons and installed Lucide icons. The existing system does not need a component framework.

## Feature boundaries

The homepage, sample tour, documentation and metadata must describe the same supported features. The sample tour has no connection to the local engine and saves samples only for the current page visit. Preserve header/footer destinations and the full CLI/configuration reference.

Use actual screenshots and sample media to explain capabilities. See `public/SOURCES.md` for asset and design attribution.
